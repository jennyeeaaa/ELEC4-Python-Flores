P1 - Student Grade Calculator

Description

A simple menu-driven Student Grade Calculator built using Python. It allows users to enter student grades and calculate the average, highest grade, lowest grade, and pass or fail status.

Features

* Accept multiple student grades
* Calculate the average grade
* Display the highest grade
* Display the lowest grade
* Check pass or fail status
* Display all grade results
* Validate grades from 0 to 100
* Handle invalid inputs and menu choices

Functions

* get_grades() – Accepts and validates student grades.
* calculate_average() – Calculates the average grade.
* get_highest() – Returns the highest grade.
* get_lowest() – Returns the lowest grade.
* check_result() – Determines whether the student passed or failed.
* display_results() – Displays all grade results.
* display_menu() – Shows the available menu options.
* main() – Controls the program execution.

How to Run

Open the project terminal and use:

python P1-Functions/main.py

Passing Grade

The passing average is 75. Grades below 75 are considered failed.
