# P4 - Safe Menu Program

## Description
A menu-driven Python program that demonstrates exception handling. It handles common errors when performing division and opening files without crashing.

## Features
- Divide two numbers
- Handle invalid numeric input
- Handle division by zero
- Open and display file contents
- Handle missing files
- Handle invalid menu selections
- Return to the menu after an error

## Exception Handling Used
- ValueError - Handles non-numeric input.
- ZeroDivisionError - Handles division by zero.
- FileNotFoundError - Handles missing files.

## Keywords Used
- try
- except
- else
- finally

## How to Run
Open the project terminal and enter:

python P4-/p4_exceptions.py
