# P3 - Student Record Manager

## Description
A menu-driven Python program that manages a collection of student names using lists and sets.

## Features
- Add student names
- Remove student names
- Search students using partial names
- Display all students in alphabetical order
- Show the total number of students
- Prevent duplicate entries regardless of uppercase or lowercase letters

## Data Structures Used
- List - Stores the student names in the program.
- Set - Checks duplicate names and ensures each name is unique.

## How to Run
Open the project terminal and enter:

python P3-Lists-and-Sets/p3_record_manager.py

## Technologies Used
- Python
