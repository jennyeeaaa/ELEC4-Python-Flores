# P2 - Custom Module: Student Utils

## Description
A Python program that demonstrates how to create and import a custom module. It uses reusable functions to calculate and display student grade results.

## Files
- student_utils.py - Contains functions for calculating the average, checking pass or fail, and getting the highest and lowest grades.
- p2_main.py - Main program that accepts grades and uses the custom module.

## Features
- Accept multiple student grades
- Calculate the average grade
- Display the highest grade
- Display the lowest grade
- Check pass or fail status
- Display the report generation date and time
- Validate grades from 0 to 100

## Import Styles Used
- import student_utils
- from student_utils import calculate_average

## Built-in Module
- datetime - Displays the date and time when the report is generated.

## How to Run
Open the project terminal and enter:

python P2-Modules/p2_main.py
