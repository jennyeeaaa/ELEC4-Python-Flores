## Description
A Python program demonstrating inheritance and polymorphism using a parent class and child classes.

## Classes
- Person – parent class with common attributes and introduce() method.
- Student – child class with student ID and course.
- Teacher – child class with subject and employee ID.

## Concepts Demonstrated
- Inheritance using Person as the parent class.
- super().__init__() to initialize common attributes.
- Method overriding using introduce().
- Polymorphism by storing different objects in one list and calling introduce() in a loop.

## How to Run
Run the following command:

`py p8_inheritance.py`
