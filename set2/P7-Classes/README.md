## Description
A Python program that demonstrates Object-Oriented Programming (OOP) using classes and objects to manage student information.

## Classes
- Student – stores and updates student information.
- Subject – stores subject details.
- Section – holds and displays multiple student objects.

## Features
- Creates three student objects.
- Displays student information.
- Updates student details and grades.
- Uses a private grade attribute.
- Validates grades from 0 to 100.

## How to Run
1. Open the terminal.
2. Navigate to the P7-Classes folder.
3. Run:

`py p7_classes.py`
