## Description
A Python program that demonstrates recursive functions. It includes factorial, Fibonacci, sum of numbers, and recursive searching.

## Functions
- Factorial – calculates the factorial of a number.
- Fibonacci – displays the Fibonacci sequence and nth term.
- Sum of Numbers – calculates the sum from 1 to n.
- Search – searches for a target value in a list recursively.

## How to Run
1. Open the terminal.
2. Navigate to the P6-Recursion folder.
3. Run:

`py p6_recursion.py`
